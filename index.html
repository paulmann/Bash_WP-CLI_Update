Bash_WP-CLI_Update

Update a hundred WordPress sites without touching a browser

Bash and WP-CLI maintenance kit for fleets of WordPress sites: core, plugin and theme updates, database repair and optimisation, cache flush, per-site logging and safe re-runs.

What it does

  • Core, plugin and theme updates in one run
  • Database repair, optimisation and cache flush
  • Per-site logs and dry-run mode before changes
