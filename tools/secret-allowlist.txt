# Known-benign places for tools/scan-secrets.sh
#
# Format, one entry per line:
#   path-glob|line-substring|reason
#
# An entry says: this is a placeholder, a marker, a test fixture or
# documentation, and a human has read the line. The path glob and the line
# substring are both matched case-insensitively, because names in code are upper
# case while the prose around them is not. The substring may be empty, which
# allowlists every hit in that file -- do that only for a file that documents
# secret shapes on purpose.
#
# Rules for adding an entry
#   1. Run the scanner with --show-values and read the line. Never allowlist
#      something you have not read.
#   2. Prefer fixing the code over allowlisting it. An entry is a decision that
#      this shape will keep appearing, not a way to silence a warning.
#   3. Keep the substring as specific as possible, so a real secret on a
#      neighbouring line is still reported.
#   4. Re-run `tools/scan-secrets.sh --strict` afterwards: it must exit 0.
#
# This file itself is never scanned: it quotes the shapes it documents, which
# would otherwise be reported as findings in the allowlist.
